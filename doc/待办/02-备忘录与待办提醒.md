## 能力边界（已核实）

| 能力 | 待办 Reminders | 备忘录 Notes |
|---|---|---|
| 列清单 / 文件夹 | ✅ `lists()` | ✅ `folders()` |
| 列条目 | ✅ `reminders()` / `list_reminders()` | ✅ `recents()` / `in_folder()` / `iter_all()` |
| 读单条 | ✅ `get()` | ✅ `get(with_attachments=True)` |
| **增量同步游标** | ✅ `sync_cursor()` + `iter_changes()` | ✅ `sync_cursor()` + `iter_changes()` |
| 渲染 / 导出 | — | ✅ `render_note()` → HTML；`export_note()` → HTML 落盘 |
| **新建** | ✅ `create()` | ❌ **无此方法** |
| **修改** | ✅ `update()` | ❌ **无此方法** |
| **删除** | ✅ `delete()` | ❌ **无此方法** |
| 子项 | ✅ 标签 / URL 附件 / 重复规则 / 位置提醒，均可增删改 | ❌ |
| 已知限制 | hashtag 改名在 Apple web app 侧可能不生效；`create()` 传 naive datetime 按 **UTC** 解释 | 密码锁定的备忘录 `NoteLockedError`，正文读不到 |

**结论**

- **待办**：读 + 写 + 勾选 + 清单 + 标签 + 附件 + 重复规则 + 位置提醒，且**有增量游标** ——
  可以做成真正的本地镜像（云端改动能增量拉、本地改能推回），就是你要的"像云盘同步一样"。
- **备忘录**：能拿列表 / 文件夹 / 正文 / 附件，能渲染成 HTML。
  **写不进去** —— pyicloud 的 Notes 服务没有任何写方法。
  要写只能走 `api.notes.raw`（直连 CloudKit client，自己构造 Apple Notes 的压缩 protobuf
  record）。工程量另算，**先不做**，等只读版本跑起来再评估。

## 认证（已核实：**不需要浏览器模块**）

> ★ 修正 2026-10-13：上一轮曾推荐"开浏览器过登录、拿 cookie 喂协议"。
> **该推荐作废** —— pyicloud 自己已经把整条认证链实现完了，见下表。
> 于是 107 MB 的 WebEngine 和 CDP 进程管理**都不用付**。
> 详见 `doc/认证与取数路径评估.md` 的「修正」一节。

已核实的能力（全部现成，无需自写）：

| 需求 | pyicloud 提供 |
|---|---|
| 中国大陆账号 | 构造参数 `china_mainland=True`（**本机在国内，必须开**） |
| 2FA 取码 | `requires_2fa` → `request_2fa_code()` |
| 2FA 提交 | `validate_2fa_code(code)` |
| 免反复 2FA | `trust_session()` —— Apple 记住本机，之后数周不再要码 |
| 安全密钥 | `security_key_names` / `fido2_devices` / `confirm_security_key()` |
| 旧 2SA 流程 | `trusted_devices` / `send_verification_code()` / `validate_verification_code()` |
| 会话保活 | 构造参数 `refresh_interval`（默认 300 秒）—— 正好对上"不低于 5 分钟"的约束 |

[ ] 引入 pyicloud（timlaing fork）：`pip install --target` 进 `sidecar/runtime`，只用库不用 CLI

[ ] 登录链路：Qt 侧弹窗收 2FA 码（不能只靠命令行）；首次登录后调 `trust_session()`

[ ] 凭据存储：keyring 或加密文件，禁止明文落盘；确认与现有 QSettings 不混放

[ ] 会话过期处理：token 失效时返回可识别错误码，界面提示"需要重新登录"而非静默失败

[ ] 测试账号约定：**用副 Apple ID 验证**，不用主力号（避免风控锁号）

## 备忘录（Notes）—— 只读镜像

[ ] 读取：文件夹 + 列表 + 详情 + 本地搜索（`recents` / `folders` / `in_folder` / `iter_all`）

[ ] 渲染：优先 `render_note()` 拿 HTML（保留加粗/列表/表格等格式），而非 `note.text` 纯文本

[ ] 附件：先只显示占位与元数据（`filename` / `uti` / `size`），不做内联渲染与下载

[ ] 增量镜像：同样用 `sync_cursor()` + `iter_changes()` 只拉变化

[ ] 密码锁定的备忘录：`NoteLockedError` → 列表里显示条目但标"已锁定，无法读取"

[ ] 写入：**明确不做**（见能力边界）。列在"待评估"，不做承诺

## 风险与边界

数据边界：端到端加密的数据（钥匙串密码、开启 ADP 后的受保护项）一律不在范围内。

法律与条款：使用非官方客户端访问违反 Apple 服务条款，存在账号风控风险；
仅用于本机自查，不公开分发凭据相关实现。

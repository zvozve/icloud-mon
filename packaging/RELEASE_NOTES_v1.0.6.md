## iCloudMon v1.0.6

Windows 上 iCloud Drive（Microsoft Store 版）同步状态监控工具。**只读** iCloud 自己的 SQLite 状态库，界面上每个计数都是真实值，不是估算。

> **本次是修复版**，在 v1.0.5（64 位 + Qt 6 大改版）基础上修掉两个日志相关的问题：退出时的崩溃（会往磁盘堆转储）与运行日志每次启动被清空。界面与用法无任何变化，直接覆盖安装即可。

### 修复

- **退出时的段错误（退出码 139）**：此前每次正常退出，进程都会在收尾阶段以 `0xC0000005`（访问违例）结束，Windows 错误报告随之在 `%LOCALAPPDATA%\CrashDumps\` 留下一个 **5~8 MB** 的转储文件。程序本身看起来一切正常（窗口正常关闭、日志完整、功能不受影响），所以这个毛病一直被当成"不影响使用"搁置 —— 但每次退出都往磁盘里堆几十兆，而且会把将来真正需要排查的崩溃转储淹没，确实该修。

  - **根因**：程序收尾时先关闭了日志系统，之后才开始销毁内部对象，而这些对象的销毁路径里还在往日志里写字 —— 写进了已经被销毁的日志器，于是空指针解引用。
  - **修法**：把日志的关闭时机挪到所有对象销毁**之后**（顺带保住了退出阶段的诊断日志，如「旁路已退出」），并在日志入口加了一道总闸：日志系统关闭后，任何写日志的调用都安全地变成空操作。同时堵住了同一个根因的另一条路径 —— Qt 在窗口销毁阶段吐出的告警消息原先绕过了日志入口直接写日志，也已收口。
  - **验证**：同一退出路径连跑 3 次，退出码由 **139 → 0**，**不再产生任何转储**，退出阶段的日志照常落盘。
  - 影响：升级后 `CrashDumps` 里不会再新增本程序的转储。已存在的历史转储可以放心删除。

- **运行日志每次启动被清空，「保留最近 30 天」从未生效**：此前同一天内重启程序，当天的日志文件会被**清空重写** —— 上一次运行到底发生了什么，重启后就查不到了，而这恰恰是最需要看日志的时候。同时「保留 30 天」因为一个参数错位而完全没生效，旧的日志文件会一直堆在 `log\` 目录里没人清理。

  - **根因**：日志库的按天切分组件，第 4 个参数其实是「**是否清空已有文件**」，原代码按「保留几个文件」去传，导致两个参数整体错位一格；而 `bool` 能接受任何整数、另一个参数只是静默截断，所以编译器也不会报警。
  - **修法**：按正确的参数顺序传入，日志改为**追加**；「保留 30 天」现在真正生效（换日时自动删除更早的文件）。另外该组件本身只支持按天切分、不支持按文件大小切分，文档里原先那句「单日超 20 MB 再切」已删除。
  - **验证**：连跑 3 次，日志文件逐次变长（追加生效），启动记录条数 1 → 2 → 3 递增，不再被清空。

### 与 v1.0.5 的关系

v1.0.5 是底层大改版（**32 位 → 64 位**、**Qt 5.15 → Qt 6.8.3**、数据层改为内嵌 Python 旁路）。若你是从 **v1.0.4 或更早**升级，请先看 v1.0.5 的发布说明了解不兼容变化（尤其是"仅支持 64 位 Windows"这一条）。本版未引入任何新的不兼容变化。

### 功能

- **六个页面**：首页总览 / 云盘细节 / 相册 / 密码 / 书签 / 设置（仿 UWP NavigationView 左侧导航，顺序与默认启动页可配）
- **真实同步状态**：上传 / 下载 / 删除三队列（含字节数）、云端文件状态分布、待处理项、回收站（可恢复，带原始路径）
- **卡死检测**：有任务在跑但队列计数持续停滞超阈值 → 红色告警 + **Windows 系统通知**
- **iCloud 进程管理**：一键重启（正确处理 Store 版 AUMID，不会「只能杀不能起」）
- **四类同步**：云盘 / 相册 / 密码 / 书签 各自状态
- **待处理项 / 回收站点击定位**：点一下直接在资源管理器跳到该文件或它原所在目录
- **运行日志**：按天切分、保留 30 天，设置页可查看路径并一键打开
- **退出按钮执行后台最小化**开关（设置页，默认关闭）；托盘图标右键「显示主窗口 / 退出」，双击托盘唤回窗口

### 亮点

- **单文件绿色版**：整个程序（Qt 运行时、QML 模块、Python 旁路）压进**一个 exe**，双击即用、**无需安装**
- **单实例**：重复双击只会把已有窗口调到前台
- **exe 内嵌图标 + 版本信息**：资源管理器 / 任务栏 / Alt-Tab 显示正常，文件属性可看版本
- **未安装 iCloud 也能跑**：界面照常显示并提示，不崩溃

### 系统要求

- 64 位 Windows 10（1809+）/ 11
- 需已安装并登录 iCloud（Store 版）才能读到实际数据；未安装时程序仍可运行并给出提示

### 说明

- 本程序对 iCloud 数据**只读**：不修改、不上传、不删除任何文件
- 已知问题：无。v1.0.5 及以前遗留的退出段错误已在本版修复。

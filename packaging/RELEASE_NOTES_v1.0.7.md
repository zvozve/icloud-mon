## iCloudMon v1.0.7

Windows 上 iCloud Drive（Microsoft Store 版）同步状态监控工具。**只读** iCloud 自己的 SQLite 状态库，界面上每个计数都是真实值，不是估算。

> **本次是修复版**：修掉「同步根目录」相关的两处毛病，外加后台临时文件泄漏。界面布局与用法**无任何变化**，直接覆盖安装即可。

### 修复

- **「同步根目录」一直显示成默认路径，设置里选目录还报「目录不存在」**。程序本可以从 iCloud 自己的数据库反推出真实的同步根（用户把 iCloud 目录挪到别处也能自动找到），但这条推导**实际上从未生效**；同时设置页选完目录后的校验也总会失败 —— 两个毛病叠在一起，表现为：界面显示的根路径不存在、命令栏「打开目录」报错、手动指定正确的目录也存不进去。

  - **根因一**：推导结果做了缓存，但缓存把"没推出来"时的兜底值也一起存了进去。程序启动时先问过一次（那时还没读库、必然推不出来），于是兜底路径被钉进缓存；此后真正带着数据库去推导的那次调用被缓存挡掉，**推导等于没跑**。
    **修法**：缓存只存真正推出来的结果，没推出来就留给下一次再试。
  - **根因二**：目录选择框交出来的是 `file:///C:/...` 形式的地址，而校验代码只做了一些斜杠整理、**没有去掉前面的 `file://`**，于是得到 `file:/C:/...` —— 系统认为这个目录不存在。
    **修法**：把「用户给的路径」统一规范化（`file://` 地址 / 反斜杠 / 引号 / 末尾斜杠），收口在一个地方，存进去的永远是干净的本地路径。
  - **验证**：规范化逻辑用一个**直接引用生产代码头文件**的小程序测（不是照抄一份逻辑），8 种输入（`file:///` 三斜杠、`file:/` 单斜杠、反斜杠、资源管理器「复制路径」带引号、末尾斜杠、前后空格、大写 `FILE://`）全部归一到同一个正确路径；并做了反向对照，确认**旧写法在同样输入下必定判定为"目录不存在"**。Python 侧按 `启动 → 采样` 的真实调用顺序压测，修复后拿到的正是本机真实根目录。程序启动时还会在日志里记一行 `[PATH] 同步根目录: ...`，以后再出这类问题一眼可查。

- **每次启动都会在系统盘留下约 18 MB 的临时文件，且永不清理**。程序为了在 iCloud 运行时也能读到状态库，每次都先把数据库（连同 `-wal` / `-shm`）复制到一个临时目录再只读打开 —— 这个临时目录**建了就没有删过**。一次启动留一个，一个约 18 MB（其中 16 MB 是数据库的日志文件）。长期使用能累积到几百 MB。

  - **根因**：代码里那段注释写的是「随进程退出清理」，但**实际上没有任何删除动作用**。临时目录的创建接口只管建、不负责删，需要自己配对一句删除，而这一句从来没写过。
  - **修法**：补上两个清理口，缺一不可 ——
    - **正常退出时删**：旁路进程自行退出（主程序让它读到输入结束）时执行清理；
    - **启动时扫遗留**：旁路被**强行结束**时（程序内置的看门狗发现旁路卡死会直接结束它再重新拉起，这条路径跑不到上面的退出清理）会留下一个目录，所以每次启动顺带扫掉上一次的遗留。
  - 扫描有两道保险，**宁可漏删也不误删**：① 只认本程序自己的临时目录结构；② 只删 6 小时内没有被改动过的 —— 正在运行的实例每几秒就会刷新目录，不会被误伤。
  - **验证**：模拟「两天前的遗留目录」→ 启动即被清掉；模拟「正在运行」的目录 → 保留不动；跑完一次正常退出 → 本次目录消失，`%TEMP%` 里不再新增。

### 一并包含 v1.0.6 的修复

若你从 **v1.0.5 或更早**升级，本版同时包含 v1.0.6 的两项修复：

- **退出时的段错误（退出码 139）**：此前每次正常退出都会在 `%LOCALAPPDATA%\CrashDumps` 留下一个 5~8 MB 转储。
- **运行日志每次启动被清空、「保留最近 30 天」从未生效**：日志现已改为追加写，重启后仍能看到上一次运行的记录。

### 功能

- **六个页面**：首页总览 / 云盘细节 / 相册 / 密码 / 书签 / 设置（仿 UWP NavigationView 左侧导航，顺序与默认启动页可配）
- **真实同步状态**：上传 / 下载 / 删除三队列（含字节数）、云端文件状态分布、待处理项、回收站（可恢复，带原始路径）
- **卡死检测**：有任务在跑但队列计数持续停滞超阈值 → 红色告警 + **Windows 系统通知**
- **iCloud 进程管理**：一键重启（正确处理 Store 版 AUMID，不会「只能杀不能起」）
- **四类同步**：云盘 / 相册 / 密码 / 书签 各自状态
- **待处理项 / 回收站点击定位**：点一下直接在资源管理器跳到该文件或它原所在目录
- **运行日志**：按天切分、保留 30 天，设置页可查看路径并一键打开
- **退出按钮执行后台最小化**开关（设置页，默认关闭）；托盘图标右键「显示主窗口 / 退出」，双击托盘唤回窗口

### 亮点

- **单文件绿色版**：整个程序（Qt 运行时、QML 模块、Python 旁路）压进**一个 exe**，双击即用、**无需安装**
- **单实例**：重复双击只会把已有窗口调到前台
- **exe 内嵌图标 + 版本信息**：资源管理器 / 任务栏 / Alt-Tab 显示正常，文件属性可看版本
- **未安装 iCloud 也能跑**：界面照常显示并提示，不崩溃

### 系统要求

- 64 位 Windows 10（1809+）/ 11
- 需已安装并登录 iCloud（Store 版）才能读到实际数据；未安装时程序仍可运行并给出提示

### 说明

- 本程序对 iCloud 数据**只读**：不修改、不上传、不删除任何文件
- 已知问题：无。

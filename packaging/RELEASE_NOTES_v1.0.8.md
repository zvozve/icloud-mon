## iCloudMon v1.0.8

Windows 上 iCloud Drive（Microsoft Store 版）同步状态监控工具。**只读** iCloud 自己的 SQLite 状态库，界面上每个计数都是真实值，不是估算。

> **本次是修复版**：修掉卡死时系统通知每 5 秒刷屏的问题，新增「关闭窗口后台运行时弹通知」开关，卡住的文件单击改为打开所在目录，并修好手动刷新按钮。直接覆盖安装即可。

### 修复

- **卡死时系统通知每 5 秒弹一次，严重打扰**。卡死判定由 Python 旁路每 5 秒推送一帧异常，C++ 侧本应只在「新出现 / 换了种类」时提醒；但去重逻辑先清空了「当前种类」列表，再拿它判断「是否新出现」——列表永远是空的，于是每一帧都被当成新告警，系统通知连续刷屏，通知中心被同一条消息塞满。

  - **修法**：改为与**上一帧**的种类集合做边沿比较，持续卡死只在刚进入时提醒一次；另加 10 分钟冷却，防止重启 iCloud 时同一异常反复出现-消失导致连弹。恢复提示也只在「有 → 无」的边沿给一次。
  - **顺带修正**：卡死与「下载错误」同时存在时，通知标题曾用最后一条异常的文案（例如显示成「存在下载错误码」）；现在卡死通知固定使用卡死自己的标题与详情。
  - **验证**：用假旁路按时间线注入「持续卡死 → 新增下载错误 → 恢复 → 再次卡死」四种状态，日志里系统通知只在两段卡死的起点各出现一次，中间 6 帧持续卡死与恢复过程不再重复弹窗。

- **单击卡住的文件会直接打开文件本身**。原本点击「本地未提交」或「待处理项」会走 `explorer /select` 选中并打开文件，失败时还会退回用默认程序打开——用户只想看看文件在哪。

  - **修法**：统一改为只打开该文件所在的目录，不再选中/打开文件；文件不存在时仍逐级向上找最近的存在目录。回收站条目本来就只打开原目录，行为不变。
  - **验证**：日志里「定位文件」记录显示为 `文件 -> 所在目录`，不再出现 `/select`。

- **手动「立即刷新」按钮点了没反应**。旁路收到 `refresh` 命令时只回 `reply`，但没有把新采样推给界面，而 C++ 侧不处理 `reply` 里的数据——于是按钮看着点了、数字却不动，容易被误判成「UI 没刷新」。

  - **修法**：`refresh` 改为在回 `reply` 的同时推送一帧 `snapshot`，界面立即更新。
  - **验证**：直接给旁路发 `refresh` 命令，确认 stdout 同时出现 `snapshot` 与 `reply` 两种事件。

### 新增

- **「关闭窗口后台运行时弹通知」开关**（设置页，默认开启，保持原有行为）。开启「退出按钮执行后台最小化」后，关闭窗口时可选择静默退到后台、只看托盘图标，不再每次弹「iCloud 监控仍在后台运行」的系统通知。
  - **验证**：把设置项写为关闭后启动程序，设置页截图确认开关处于关闭态；删除该设置项后恢复默认开启态。

### 关于「清空云盘回收站后 UI 仍显示内容」

排查结论：**回收站列表读的是本地 `iCloudDrive.db` 的 `local_items` 表**（`item_restore_path` 非空的行），每 5 秒重新查库、没有缓存，不是界面没刷新。本机实测该表仍有 184 条删除记录，且对应文件在 `.Trash` 目录里都还在——iCloud 客户端并没有把这些本地删除记录清掉，所以程序如实显示。外部（网页端）清空回收站后，需等 iCloud 客户端同步回写本地数据库，界面才会跟着变化。

### 功能

- **六个页面**：首页总览 / 云盘细节 / 相册 / 密码 / 书签 / 设置
- **真实同步状态**：上传 / 下载 / 删除三队列（含字节数）、云端文件状态分布、待处理项、回收站（可恢复，带原始路径）
- **卡死检测**：有任务在跑但队列计数持续停滞超阈值 → 红色告警 + Windows 系统通知（本次起不再刷屏）
- **iCloud 进程管理**：一键重启（正确处理 Store 版 AUMID）
- **运行日志**：按天切分、保留 30 天
- **退出按钮执行后台最小化** + 托盘图标管理

### 亮点

- **单文件绿色版**：Qt 运行时、QML 模块、Python 旁路压进一个 exe，双击即用、无需安装
- **单实例**：重复双击只会把已有窗口调到前台
- **只读**：不修改、不上传、不删除任何 iCloud 文件

### 系统要求

- 64 位 Windows 10（1809+）/ 11
- 需已安装并登录 iCloud（Store 版）才能读到实际数据

### 说明

- 本程序对 iCloud 数据**只读**：不修改、不上传、不删除任何文件
- 已知问题：无。

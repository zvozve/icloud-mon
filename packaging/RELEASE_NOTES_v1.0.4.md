## iCloudMon v1.0.4

Windows 上 iCloud Drive（Microsoft Store 版）同步状态监控工具。**只读** iCloud 自己的 SQLite 状态库，界面上每个计数都是真实值，不是估算。

### 本次更新

- **新增「退出按钮执行后台最小化」开关**（设置页，位置紧跟「开机自启动」）：
  - **开启** → 点退出按钮只关闭窗口（窗口从屏幕和任务栏一起消失，**不是最小化**），进程留在后台继续监控，托盘图标作为唯一入口；
  - **关闭（默认）** → 点退出按钮直接结束程序，与历史行为一致。
  - 该开关默认关闭，老用户不受影响。设置持久化保存。
- **系统托盘增强**：托盘图标右键菜单新增「显示主窗口 / 退出」；**双击托盘图标**即可重新唤回窗口。
- 设置项措辞统一为「退出按钮」，与开关实际作用一致。

### 功能

- **六个页面**：首页总览 / 云盘细节 / 相册 / 密码 / 书签 / 设置（仿 UWP NavigationView 左侧导航，顺序与默认启动页可配）
- **真实同步状态**：上传 / 下载 / 删除三队列（含字节数）、云端文件状态分布、待处理项、回收站（可恢复，带原始路径）
- **卡死检测**：有任务在跑但队列计数持续停滞超阈值 → 红色告警 + **Windows 系统通知**（窗口最小化也能收到）
- **iCloud 进程管理**：一键重启（正确处理 Store 版 AUMID，不会「只能杀不能起」）
- **四类同步**：云盘 / 相册 / 密码 / 书签 各自状态
- **待处理项 / 回收站点击定位**：点一下直接在资源管理器跳到该文件或它原所在目录
- **运行日志**：按天切分、保留 30 天，设置页可查看路径并一键打开

### 亮点

- **单文件绿色版**：整个程序（含全部 Qt 运行时、插件）压进**一个 exe**，双击即用、**无需安装**，约 27 MB
- **单实例**：重复双击只会把已有窗口调到前台
- **图形后端自适应**：默认走 ANGLE(D3D11)，绕开部分机器桌面 OpenGL 失效导致的白屏
- **exe 内嵌图标 + 版本信息**：资源管理器 / 任务栏 / Alt-Tab 显示正常，文件属性可看版本
- **未安装 iCloud 也能跑**：界面照常显示并提示，不崩溃

### 系统要求

- Windows 10 / 11
- 需已安装并登录 iCloud（Store 版）才能读到实际数据；未安装时程序仍可运行并给出提示

### 说明

- 本程序对 iCloud 数据**只读**：不修改、不上传、不删除任何文件
- 已知：进程退出阶段偶发段错误（不影响使用，功能与日志均正常）

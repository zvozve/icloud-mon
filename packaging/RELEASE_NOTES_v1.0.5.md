## iCloudMon v1.0.5

Windows 上 iCloud Drive（Microsoft Store 版）同步状态监控工具。**只读** iCloud 自己的 SQLite 状态库，界面上每个计数都是真实值，不是估算。

> **本次是底层大改版**：换到 64 位 + Qt 6，数据层改为内嵌的 Python 旁路。界面与用法基本不变，但下面的「不兼容变化」一节请先看一眼。

### 不兼容变化

- **架构：32 位 → 64 位**。单文件 exe 现在是 64 位程序，只能跑在 64 位 Windows 上（Windows 10 1809 及以上）。32 位系统不再支持。
- **界面框架：Qt 5.15 → Qt 6.8.3**。旧的 `QtQuick.Dialogs 1.3` 那套目录选择器在 Qt6 里已被替换，本版已按新 API 重做（设置页「选择 iCloud Drive 目录」功能不变）。
- **图形后端提示变了**：Qt6 移除了 ANGLE 后端，v1.0.4 说明里的 `QT_OPENGL=angle` 已失效；需要强制后端时改用它自己的变量（`QSG_RHI_BACKEND`）。

### 本次更新

- **数据层重写为独立旁路进程（Python）**：C++ 只负责界面与 iCloud 进程控制，采集/判定全部交给旁路。这样「取数」这件事只有一处实现（同一件事不写两遍），旁路进程可以被单独重启、单独测试，主界面不受影响。旁路**只读**本机 iCloud 状态库，不联网。
- **单文件版内嵌旁路运行时**：打包时自动把 Python 运行时与旁路脚本一起压进 exe，**双击即用，不需要用户装 Python**（体积因此从约 27 MB 增到约 49 MB）。
- **卡死提醒改走 Windows 通知中心**：上一版的「自绘置顶提醒条」已移除。现在卡死告警是一条**真正的系统通知** —— 会出现在右下角、留在通知中心里、错过还能回看。
  - 实现上绕开了 Qt 托盘通知在本机的死锁问题（那条路径要求单线程单元），改为在专属线程里直接调用系统通知接口。
  - **窗口正好在前台时，会额外再弹一条窗口内提醒**（系统通知可能被「专注助手」吞掉，窗口内这条一定看得见）。
  - 若你在 Windows 设置里关掉了本应用的通知，设置页会明确显示「系统通知当前不可用」，并自动退化为只在窗口内提醒 —— 不会出现「看起来发了、其实没人看见」。
- **应用标识去个人化**：程序内部的组织名/注册表位置/配置目录由作者个人标识统一改为 `iCloudMon`。升级后**首次启动会自动迁移**原有设置与历史记录（迁移前的老键会被清理，且是幂等的：第二次启动不再迁移）。
- **iCloud Drive 根目录改为自动发现**：不再假设盘符，按「环境变量 → 注册表覆盖 → 从 iCloud 自己的数据库推导 → 系统默认位置」的顺序解析。此前若你把 iCloud Drive 放在非默认位置，程序可能读错目录；现在能自己找对。设置页的「恢复默认」按钮只在确实被手动改过时才出现。
- **待办（Reminders）取数探针**：新增只读探针脚本，用于探测 CalDAV / CloudKit 两条取数路线（本版仅探测，尚未接入界面）。

### 修复

- **GPU 诊断日志误报**：此前每次启动都会打一条「5 秒内场景图未初始化」的告警，实际界面完全正常。根因是那段探针监听的是一个**一次性**信号，而它在探针挂载之前就已经发过了 —— 所以标志位永远是假，必然误报。已改为直接查询真实状态，实测启动即判定正确。

- 设置页把自绘提醒条称作「Windows 通知」，与实际行为不符，已按实际改法措辞（本版起它才是真的系统通知）。
- 目录选择对话框在新框架下的枚举取值错误（会静默按「选文件」模式打开，界面看不出问题）—— 已改用正确的对话框类型。

### 功能

- **六个页面**：首页总览 / 云盘细节 / 相册 / 密码 / 书签 / 设置（仿 UWP NavigationView 左侧导航，顺序与默认启动页可配）
- **真实同步状态**：上传 / 下载 / 删除三队列（含字节数）、云端文件状态分布、待处理项、回收站（可恢复，带原始路径）
- **卡死检测**：有任务在跑但队列计数持续停滞超阈值 → 红色告警 + **Windows 系统通知**
- **iCloud 进程管理**：一键重启（正确处理 Store 版 AUMID，不会「只能杀不能起」）
- **四类同步**：云盘 / 相册 / 密码 / 书签 各自状态
- **待处理项 / 回收站点击定位**：点一下直接在资源管理器跳到该文件或它原所在目录
- **运行日志**：按天切分、保留 30 天，设置页可查看路径并一键打开
- **退出按钮执行后台最小化**开关（设置页，默认关闭）；托盘图标右键「显示主窗口 / 退出」，双击托盘唤回窗口

### 亮点

- **单文件绿色版**：整个程序（Qt 运行时、QML 模块、Python 旁路）压进**一个 exe**，双击即用、**无需安装**
- **单实例**：重复双击只会把已有窗口调到前台
- **exe 内嵌图标 + 版本信息**：资源管理器 / 任务栏 / Alt-Tab 显示正常，文件属性可看版本
- **未安装 iCloud 也能跑**：界面照常显示并提示，不崩溃

### 系统要求

- 64 位 Windows 10（1809+）/ 11
- 需已安装并登录 iCloud（Store 版）才能读到实际数据；未安装时程序仍可运行并给出提示

### 说明

- 本程序对 iCloud 数据**只读**：不修改、不上传、不删除任何文件
- 已知：进程退出阶段偶发段错误（不影响使用，窗口正常关闭、功能与日志均正常），尚未定位
